# Offline demo / 离线演示

First launch defaults to offline demo mode. No API key is required. Demo recommendations are bundled samples, not live or personalized advice. Demo browsing does not request location, fetch map previews, search images or send user input to AI. Key validation is a separate, explicitly initiated network request.

首次启动默认离线演示，无需密钥。演示内容不是实时或个性化建议；浏览演示不请求定位、加载在线地图或图片，也不向 AI 发送输入。主动验证密钥仍需联网。

In Settings, turn off Offline demo mode, select a provider, validate a key and consent to data sharing before requesting live AI results. Dream research begins only when the user chooses to start it. Existing saved data is not deleted when switching modes.

在设置中关闭离线演示，选择服务商、验证密钥并同意发送资料后，才能获取真实 AI 推荐。梦游研究仅在用户主动开始时运行。切换模式不会删除已有数据。

Reviewer: open the app without a key to browse sample cards and detail pages. Samples do not represent real bookings, venue availability, verified weather, prices or transport. Maps and live research are intentionally unavailable in demo mode.
