# My Journey Dream — Public Edition

Independent public-edition source tree for the iPhone journey discovery app. This repository does not contain the private edition's Git history, saved profile, API keys, or personal resources.

Status: release preparation in progress. Do not submit this build to App Store Connect until localization, provider parity, privacy disclosures, screenshots, accessibility, and device testing are complete.

Demo journeys are illustrative. Verify mutable travel, health, entry, and safety information with official sources before booking or departure.
